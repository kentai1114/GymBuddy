# FORGE — AI Gym Workout Assistant

知道你之前做過咩 → 推薦今日應該練咩 → 做緊時即時帶住你完成 → 自動累積進步。

## Features

1. **今日訓練** — 部位、預計時間、上次訓練、今日目標
2. **Workout History** — 完成記錄與容量
3. **AI Workout Suggestion** — 依恢復狀態 / 上次部位 / 目標自動排課
4. **Exercise Mode** — 完成組數、重量訓練 Rest Timer、5 mins running 計時
5. **Exercise Database** — Muscle / Equipment / Instructions / YouTube demo
6. **AI Coach** — 對話式訓練建議
7. **Weekly Overview** — 本週日曆與部位覆蓋

## Stack

- Vite + React + TypeScript
- React Router
- LocalStorage persistence（無需 backend）

## Run

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (default `http://localhost:5173`).
